First stable release. Download the `.apk` below, install it and open the **Phonon** app once.

## What it does

- Adds Phonon as a system text-to-speech engine for Android, working with **TalkBack** and every
  app that uses Android's text-to-speech API.
- Speech is generated **offline**, on the phone. The `phonon-40m-multilingual` model and all 102
  catalog voices are bundled in the APK: nothing to download.
- Languages: Portuguese (Brazil), English (UK, US and character voices), Spanish (Spain and
  Mexico), French and German, each with a selectable default voice.
- System and TalkBack speech rate and pitch work, plus an optional extra speed multiplier.
- Speech stops instantly when interrupted, and leading silence is trimmed for a faster response.
- Adjustable expressiveness (the model's most expressive setting is the default) and number of
  processor cores (3 by default).
- The model is unloaded when no app uses the engine any more, giving its memory back.
- The interface is in English, Portuguese, Spanish, French and German, following the phone's
  language.

Needs Android 7 or later on a 64-bit ARM processor.
