Download the `.apk` below and install it over the previous version.

## Changes

- The interface is translated into every language Phonon speaks: English, Portuguese, Spanish,
  French and German. It follows the phone's language.
- The model is unloaded when no app uses the engine any more (for example after choosing another
  engine), giving its memory back. It loads again the next time the engine is used.
- The default number of processor cores is now 3: the runtime gains little past three threads,
  and the extra cores on most phones are the slower ones.
- Removed the response-time measurement and the experimental faster audio decoder. Tests showed
  the decoder saved about 15 ms at an audible cost in quality.
- The APK is now named `phonon-<version>.apk`.
